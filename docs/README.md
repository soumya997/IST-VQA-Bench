# ISTVQA Project Page

Academic project page for:

**ISTVQA: A Diagnostic Framework for Enabling Indic Scene-Text VQA in Small Vision-Language Models** (ICVGIP 2026)

Template adapted from [nerfies](https://github.com/nerfies/nerfies.github.io) (same style as [Shilalekhya Binarization](https://ihdia.iiit.ac.in/shilalekhya-binarization/)).

## Preview locally

```bash
cd project_page
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Deploy

Host the contents of `project_page/` on GitHub Pages, Netlify, or any static host (e.g. `username.github.io/istvqa/`).
